# dataset_tools

Dataset builders, ingesters, synthetic generators, trainers and Colab notebooks for the Bifrost NØX
firewall. Lives at the repo root but is **not imported by the firewall at runtime**; datasets and built splits are git-ignored
(`*/data/`), only the tooling is tracked.

```
dataset_tools/
├── paths.py          # repo location (BIFROST_REPO, default: parent of this folder) + artifacts_dir()
├── waf/              # web-attack classifier (text service)
│   ├── data/         #   seed_*.jsonl, external/ pools, build/   (local only, large)
│   ├── v2/           #   shape-balanced dataset builder (benign, payloads, shapes, build, make_notebook)
│   ├── build_dataset.py  ingest.py  ingest_har.py  _ingest_kaggle_batch.py   # v1 pipeline
│   ├── synth_benign.py  synth_cmdi.py  sources.py                            # generators / loaders
│   ├── train.py  eval.py  shadow_mitm.py                                     # baseline trainer, eval, shadow proxy
│   ├── train_transformer.ipynb   # v1 Colab notebook
│   └── train_v2.ipynb            # v2 bake-off notebook (generated by v2/make_notebook.py)
├── router/           # text router (code / web_request / prose)
│   └── build_dataset.py  train.py
├── image/            # image-service evaluation corpus
│   └── synth_cases.py
└── tests/            # tests for the tools (conftest puts the repo and this folder on sys.path)
```

## Running

Run from the repo root; trained artifacts are written into `ml/<type>/artifacts/` (where the runtime reads them).

```bash
export PYTHONPATH=.

# WAF v2 dataset (needs the public repos cloned under ~/waf_datasets: patt/, seclists/, fuzzdb/)
WAF_V2_DENYLIST="term1,term2" python -m dataset_tools.waf.v2.build --root ~/waf_datasets --out ~/waf_datasets/build_v2
python -m dataset_tools.waf.v2.make_notebook        # regenerates train_v2.ipynb

# WAF v1 baseline
python -m dataset_tools.waf.build_dataset && python -m dataset_tools.waf.train && python -m dataset_tools.waf.eval

# Router
python -m dataset_tools.router.build_dataset && python -m dataset_tools.router.train

# Tool tests (and the firewall's own image tests use image/synth_cases.py)
python -m pytest dataset_tools/tests -q
```

`WAF_V2_DENYLIST` drops any record containing one of the comma-separated terms (use it for engagement or
customer names; never write those into tracked files).
